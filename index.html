Find My Attack Path

An open-source, click-through map of the Active Directory attack chain — recon to domain dominance to hybrid/cloud pivot — built for learning and red-team lab prep.

The chain across the middle is the kill-chain: phases run left to right. Each phase branches into the techniques that belong to it. A technique connects to the tool(s) used to run it and, where one applies, the CVE it exploits.

Click any node — its connections light up ("wires" to every technique in a phase, or to the tool/CVE a technique uses) and the detail panel shows what it does, its prerequisite, and the detection artifact a blue team would actually see.

Drag to pan, scroll/pinch to zoom, drag a node to pin it. Every floating window can be dragged from its header, resized from any side or corner, or minimized to the bottom dock. Use the toolbox at the lower right for layout presets, shortest-path highlighting, bookmarks, scratchpad notes, custom nodes, color controls, and exports (JSON, CSV, CSS, SVG, PNG, Markdown).

Every node is a markdown file under docs/ — the graph fetches docs/manifest.json and the files it lists on load, so nobody edits HTML to add or update a phase, technique, tool, or CVE.

Full format and examples: CONTRIBUTING.md.
