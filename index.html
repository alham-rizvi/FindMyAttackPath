Find My Attack Path

An open-source, click-through map of the Active Directory attack chain — recon to domain dominance to hybrid/cloud pivot — built for learning and for red-team hackathon prep.

The dark chain across the middle is the kill-chain: phases run left to right. Each phase branches into the techniques that belong to it. A technique connects to the tool(s) used to run it and, where one applies, the CVE it exploits.

Click any node — its connections light up ("wires" to every technique in a phase, or to the tool/CVE a technique uses) and the detail panel shows what it does, its prerequisite, and the detection artifact a blue team would actually see.

Drag to pan, scroll/pinch to zoom, drag a node to pin it. Use the search box to jump to a technique or tool by name, or the Show chips to hide a whole node type. Tool & resource index includes searchable tools and references plus recent project commits. Open the toolbox at the lower right to customize background and node colors, expand node details, or download selected phases as JSON, CSV, CSS or SVG. Mermaid diagrams can also be opened in a large viewer and downloaded as SVG or editable source.

Every node is a markdown file under docs/ — the graph fetches docs/manifest.json and the files it lists on load, so nobody edits this HTML to add or update a phase, technique, tool or CVE.

To add one: fork the repo, drop a new .md file (frontmatter + description) in the right docs/<type>/ folder, list it in manifest.json, and open a PR — include a Mermaid diagram in the body (a fenced ```mermaid block) if a custom flow helps explain it. Merge it and it's live on the graph.

Full format and examples: CONTRIBUTING.md.
